Tip

Tokenization, prompting and embeddings each have a runnable notebook: 01_tokenization, 02_prompting and 03_embeddings_rag. They are the quickest way to build intuition, because you change a value and watch the result.

How to learn from each level

  1. Read the guide page first so you know what to look for.
  2. Run the level and read its output.
  3. Open the level's Python file. The comments at the top explain the concepts.
  4. Change one thing and run it again.
  5. Do the exercise, if there is one.
  6. Answer the self-check questions out loud.

When you get stuck

Search the guide with the box at the top (press /), check the glossary, then the troubleshooting table in the project README.
